# candyfloss-picocalc

A port of the BBC Micro game Candyfloss to Picomite Basic. This port requires the latest beta version of Picomite as it uses the new `bbc play sound` command: https://github.com/UKTailwind/PicoMite/releases/tag/PicoMite-V6.03.02b6. Tested on a PicoCalc using the RP2350 build.
